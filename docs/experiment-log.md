## 결정 카드 정탐/오탐 (PLAN §8 M2 완료 기준)

턴 분석이 올린 카드마다 한 줄씩 적는다. 정탐은 사람이 판단해야 할 결정이 맞았던 것, 오탐은 결정이 아니었던 것, 놓침은 카드는 없었지만 결정이었던 것이다.

|---|---|---|---|---|
