# ADR-0022: Claude 탭 아래에 일반 입력창을 둔다

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 에이전트 (미누 피드백: "문구"를 치니 "ㄱ ㄷ"처럼 자모로 쪼개짐)

## 결정
Claude 탭 아래에 일반 텍스트 입력창을 둔다(기본 켬, 탭 머리의 키보드 버튼과 설정에서 끔). 입력은 운영체제 입력기가 완성하고, Enter를 누르면 한 번의 bracketed paste + 별도의 Enter로 Claude에 보낸다. Shift+Enter는 줄바꿈, 비어 있을 때 Esc는 Claude 중단으로 넘긴다. 입력기가 조합 중일 때는 Enter를 처리하지 않는다. 메뉴 선택 같은 직접 입력은 터미널을 클릭해서 한다.

## 이유
영어로 치다 한글로 바꾼 직후 첫 음절이 자모로 쪼개지는 것은 Claude Code 프롬프트의 알려진 버그다(iTerm2 등 다른 터미널에서도 보고됨, 셸에서는 안 생김). 알려진 우회법은 "다른 곳에서 쓰고 붙여넣기"뿐인데, 입력창이 그 일을 자동으로 한다. 붙여넣기로 들어온 완성된 텍스트는 쪼개지지 않는다(실제 claude e2e로 두 줄 한국어 프롬프트 확인).

## 대안
- xterm의 조합 처리 수정: 원인이 Claude Code 쪽이라 고쳐지지 않는다.
- Claude Code 수정을 기다리기: 그동안 한국어 사용자가 계속 불편하다.

## 결과와 대가
`/` 명령 자동 완성, `@` 파일 언급 자동 완성 같은 Claude 입력칸의 보조 기능은 입력창에서는 보이지 않는다(보낸 텍스트 자체는 그대로 처리된다). 그런 기능이 필요하면 터미널을 클릭해 직접 친다.
