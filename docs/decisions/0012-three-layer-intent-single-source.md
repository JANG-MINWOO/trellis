# ADR-0012: 의도 레이어 3층, 원본 하나

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누 (대화로 합의)

## 결정
의도 데이터는 동작(업무 용어) / 결정과 결과(결과·대가) / 구현(기술 용어) 3층을 구분해 저장한다. 비개발자용·개발자용 문서를 따로 만들지 않고, 원본 하나에서 보는 사람에 따라 펼쳐지는 층만 다르게 한다. v1은 개발자 화면만 만든다.

## 이유
두 벌로 나누면 어긋난다. 비개발자는 기술 용어를 몰라도 결과와 대가는 판단할 수 있다. 층이 나뉘어 있으면 원하는 사람은 한 층씩 내려가 볼 수 있다. 근거: `docs/BACKGROUND.md` §2.11.

## 대안
비개발자용·개발자용 문서 분리: 원본이 둘이 된다.

## 결과와 대가
데이터 모델에 층 구분이 처음부터 들어간다. 위 층의 번역은 아래 층 원문과 항상 연결하고, 번역 검증은 개발자가 한다.
