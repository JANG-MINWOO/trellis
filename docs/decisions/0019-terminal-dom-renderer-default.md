# ADR-0019: 터미널은 기본적으로 DOM 렌더러로 그린다

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 에이전트 (미누 피드백: 셸 탭에서 입력이 안 보임)

## 결정
xterm의 WebGL 렌더러는 설정(터미널 → GPU 가속 렌더링)으로 켜는 선택 사항으로 바꾸고, 기본은 DOM 렌더러로 그린다.

## 이유
미누 환경의 셸 탭에서 "한글은 한 글자만 보이다 말고, 영어는 안 보이고, Enter도 안 됨" 증상이 있었다. 자동 테스트(Finder와 같은 최소 환경 포함 10여 회)로는 셸이 입력을 정상 처리했고 재현되지 않았다. 증상은 "셸은 돌고 있는데 화면이 다시 그려지지 않는" 경우와 맞는다(입력기 조합 창만 DOM이라 보임). WebGL은 화면이 멈춰도 감지할 방법이 없지만 DOM 렌더러는 그런 식으로 멈추지 않는다.

## 대안
WebGL 유지 + 원인 추적: 재현이 안 돼 추적할 수 없었다. 한글 입력기 조합 상태가 꼬이는 경우일 가능성도 남아 있어, 새 빌드로 미누가 다시 확인한다.

## 결과와 대가
출력이 아주 많을 때 그리기가 조금 느릴 수 있다. 원인이 렌더러가 아니었다면 이 결정은 효과가 없고, 그때는 입력기 쪽을 조사한다(worklog에 기록).
