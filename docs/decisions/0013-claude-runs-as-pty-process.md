# ADR-0013: Claude 탭은 셸 없이 claude를 직접 실행

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 에이전트 (구현 결정)

## 결정
Claude 탭의 pty 프로세스는 셸이 아니라 claude 실행 파일 자체다. 인자(`--settings`, `--continue`, `--session-id`, 사용자 추가 인자)는 argv 배열로 넘긴다. 셸 명령이 필요하면 별도의 셸 탭을 쓴다. macOS에서는 시작할 때 로그인 셸 환경(PATH 등)을 읽어 claude에 넘긴다.

## 이유
셸에 명령 문자열을 타이핑하면 zsh·PowerShell 따옴표 규칙, 경로의 공백, 셸 설정 파일의 PATH 재정렬 문제가 생긴다. 직접 실행하면 claude가 끝나는 시점을 정확히 알 수 있어 "다시 시작 / 이어서" 화면을 띄울 수 있다.

## 대안
셸을 띄우고 `claude …`를 타이핑: 셸별 인용 규칙과 PATH 문제가 생긴다.

## 결과와 대가
Finder에서 실행한 macOS 앱은 셸 PATH를 못 받으므로 로그인 셸 환경을 읽는 단계가 필요하다(실패하면 기본 PATH + 알려진 경로로 대체).
