# ADR-0021: 개발 중 갱신은 install:local, 배포·자동 업데이트는 서명 후에

- 상태: 개발 루프는 채택, 배포·자동 업데이트는 제안 (M5에서 확정)
- 날짜: 2026-10-09
- 결정한 사람: 미누 요청 + 에이전트 제안

## 결정
- 개발 중: `npm run dev`(watch)로 바로 확인한다. 안정 빌드를 바꿀 때는 `npm run install:local` — dmg 없이 앱 폴더를 만들어 `/Applications/Trellis.app`을 교체한다. Trellis가 실행 중이면 지금 빌드해 두고, 종료하는 순간 교체 후 다시 연다(Trellis 안의 Claude에서 실행해도 된다). 상태 바와 설정 정보에 `버전+커밋`을 보여 줘 어떤 빌드인지 항상 안다.
- 남에게 줄 버전: `package.json` 버전을 올리고 `v*` 태그를 푸시하면 CI가 dmg·exe를 만들어 릴리스에 올린다(이미 구성됨).
- 자동 업데이트(제안): electron-updater가 앱을 켤 때 릴리스의 `latest.yml`/`latest-mac.yml`을 읽어 새 버전을 받고 재시작 때 설치한다. 조건: ① macOS 자동 업데이트는 Developer ID 서명·공증이 필요하다(연 $99) ② 비공개 저장소의 릴리스는 토큰 없이 못 받으므로, 배포용 공개 릴리스 저장소나 정적 서버(S3/R2 등)를 둔다 ③ Windows는 서명 없이도 동작하지만 SmartScreen 경고가 뜬다.

## 이유
매번 dmg를 지우고 다시 까는 것은 느리고, 개발 중에는 서명·업데이트 서버가 필요 없다. 자동 업데이트는 서명과 배포 채널이 정해져야 의미가 있다.

## 대안
개발 중에도 dmg를 매번 빌드·설치: 느리고 수동이다.
자체 업데이트 서버를 지금 구축: 사용자가 미누 한 명인 지금은 과하다.

## 결과와 대가
`install:local`은 지금 macOS 전용이다(Windows는 `dist:win` 후 설치 파일 실행).
