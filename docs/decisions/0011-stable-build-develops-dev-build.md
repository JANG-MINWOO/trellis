# ADR-0011: 안정 빌드로 개발 빌드를 고친다

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누 (셀프 업그레이드 구조 제안) + 에이전트 보완

## 결정
Trellis로 Trellis를 개발할 때는 패키지된 안정 빌드에서 Claude를 실행해 `main`을 고친다. 개발 빌드(`npm run dev`)는 앱 데이터 폴더를 `Trellis-dev`로 분리한다. 새 기능이 쓸 만해지면 안정 빌드를 갱신한다.

## 이유
고치는 중인 앱이 깨지면 작업 환경도 같이 사라진다. 컴파일러가 이전 단계 빌드로 다음 단계를 만드는 것과 같다. 데이터 폴더를 나누지 않으면 두 인스턴스가 같은 원장에 동시에 쓴다.

## 대안
개발 빌드로 바로 개발: 깨지는 순간 복구 수단이 없다.

## 결과와 대가
안정 빌드를 갱신하는 절차(패키지 빌드 → 설치)가 하나 더 생긴다.
