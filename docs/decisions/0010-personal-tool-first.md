# ADR-0010: 개인 도구로 시작, 검증 후 제품화 결정

- 상태: 채택 (오픈소스 공개는 ADR-0030에서 앞당겨 결정)
- 날짜: 2026-10-09
- 결정한 사람: 미누

## 결정
1차 사용자는 미누 본인이다. 실험 지표(PLAN §9)로 효과를 확인한 뒤 클라이언트 제공·오픈소스·교육용 제품화를 결정한다. 단 품질은 처음부터 바로 쓸 수 있는 제품 수준으로, 설계는 배포(크로스 플랫폼·i18n·패키징)를 열어 둔다.

## 이유
효과가 검증되지 않은 상태에서 팀 기능·서명·계정을 만들면 낭비다. 그러나 미누가 매일 쓰며 개발할 도구라 프로토타입 품질로는 실험 자체가 안 된다.

## 대안
처음부터 제품 지향: 팀·외부 사용자 기능 때문에 초기 속도가 느려진다.

## 결과와 대가
팀 공유, 계정, 코드 서명은 M5 이후로 미룬다.
