# ADR-0008: 레이아웃 B — 터미널 가운데, 패널 오른쪽

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누

## 결정
왼쪽에 프로젝트·파일, 가운데에 터미널(Claude), 오른쪽에 의도·타임라인·변경·결정·건강 패널을 둔다. 양쪽 패널은 크기 조절·접기가 된다.

## 이유
대화(터미널)가 주인공이고, 패널은 항상 옆에서 같이 보인다.

## 대안
- A(터미널 아래, 패널 위): 패널을 넓게 보지만 대화 영역이 좁다.
- A/B 전환: 구현 공수가 더 들고 지금 필요하지 않다.

## 결과와 대가
오른쪽 패널 폭이 좁아 정보 밀도를 신경 써야 한다.
