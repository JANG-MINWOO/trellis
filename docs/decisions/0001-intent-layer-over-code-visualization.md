# ADR-0001: 코드 시각화가 아니라 의도 레이어를 지키는 도구

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누 (대화로 합의)

## 결정
Trellis의 중심은 코드 의존성 시각화나 줄별 설명이 아니라, 프로젝트의 의도 레이어(동작·불변식, 결정과 그 이유, 경계와 구조)를 사람이 이해하고 책임지는 상태로 유지하는 것이다.

## 이유
AI 요약을 다시 AI 그림으로 바꾸면 사람은 그것도 안 읽는다. 전체 의존성 그래프는 실뭉치다. AI가 정체하든 완벽해지든, 의도 레이어는 사람의 이해 근거이자 AI의 입력이라 어느 미래에서도 가치가 남는다. 근거: `docs/BACKGROUND.md` §2.1, §2.6.

## 대안
- 코드 영향 시각화 도구: AI가 좋아질수록 쓸모가 줄고, 이미 리뷰 봇들이 한다.
- 자연어에 가까운 새 프로그래밍 언어: 정밀함 문제는 표기법으로 사라지지 않고, 학습 데이터가 없어 AI가 가장 못 다룬다(§2.10).

## 결과와 대가
사람의 시간은 diff 양이 아니라 결정 개수에 쓰인다. 대신 "결정"을 잘 감지해야 하는 어려운 문제(M2)를 떠안는다.
