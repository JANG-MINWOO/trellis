# ADR-0017: Claude 권한 방식은 실행할 때 고른다

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누 요청 ("처음 켤 때 default로 켤지 dangerously-skip-permissions로 켤지 선택")

## 결정
Claude를 시작하는 모든 곳(실행 카드, 새 탭, 멈춘 탭 다시 시작)에 권한 선택을 둔다: Claude 설정 따르기(인자 없음, 기본값) / 매번 확인(`--permission-mode manual`) / 파일 수정 자동 허용(`acceptEdits`) / 자동 판단(`auto`) / 계획만(`plan`) / 모든 확인 건너뛰기(`--dangerously-skip-permissions`). 기본값은 설정·온보딩에서 정하고, 프로젝트를 열 때는 기본적으로 실행 카드를 띄운다(바로 시작도 선택 가능). 탭에는 그 프로세스의 권한을 표시하고, 건너뛰기는 빨간 표시를 붙인다.

## 이유
0.1.0은 권한 인자를 넘기지 않아 Claude Code 자체 기본값(미누 환경에서는 auto)으로 열렸고, 사용자는 그게 Trellis의 기본값인지 알 수 없었다. 권한은 사람이 책임지는 결정이라 눈에 보이게 고르는 게 맞다.

## 대안
설정에만 두기: 매번 다른 방식으로 켜고 싶을 때 번거롭고, 지금 어떤 권한으로 돌고 있는지가 안 보인다.

## 결과와 대가
사용자가 추가 인자로 `--permission-mode` 등을 직접 주면 그쪽을 따른다. `manual`이 예전 `default`에 해당한다는 것은 2.1.294의 `--help` 기준이다.
