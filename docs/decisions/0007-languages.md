# ADR-0007: 언어 — 저장소 문서·커밋은 한국어, 코드는 영어, 앱은 ko/en

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누

## 결정
- 이 저장소의 문서·ADR·worklog·커밋 설명은 한국어. 커밋 형식은 Conventional Commits(`feat(scope): 설명`).
- 코드 식별자와 주석은 영어.
- 앱 UI는 첫 실행 때 한국어/영어를 고른다(i18n). Trellis가 대상 프로젝트에 남기는 기록(결정 문서 등)은 프로젝트별 "기록 언어" 설정을 따른다.

## 이유
문서는 미누가 직접 읽고 판단하는 게 핵심이라 한국어가 빠르다. 앱은 멀리 퍼뜨릴 수 있게 언어를 고를 수 있어야 한다.

## 대안
전부 영어: 기여자에게 친화적이지만 지금의 핵심 사용자(미누)의 검토 속도가 느려진다. 공개할 때 영어 README를 추가한다.

## 결과와 대가
UI 문자열은 항상 두 언어로 관리해야 한다(키 누락은 검사로 잡는다).
