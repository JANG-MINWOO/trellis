# ADR-0018: 한 프로젝트에 탭 여러 개

- 상태: 채택
- 날짜: 2026-10-09
- 결정한 사람: 미누 요청 (프로젝트에서 새 채팅 창을 여는 방법)

## 결정
한 프로젝트에서 Claude 대화와 셸을 탭으로 여러 개 연다. "중지"는 프로세스만 끝내고 탭은 남겨 그 자리에서 다시 시작하게 하고, "탭 닫기"는 탭까지 없앤다. 다른 Claude 탭이 실행 중이면 "이어서 하기"는 막는다(가장 최근 대화를 두 프로세스가 같이 열게 되므로). "이번 실행" 기준점은 프로젝트의 첫 Claude가 시작될 때만 잡는다. 타임라인은 탭이 둘 이상이면 탭별로 걸러 볼 수 있다.

## 이유
0.1.0은 프로젝트당 Claude 하나·셸 하나로 고정이었고, X 버튼이 프로세스만 지우고 화면에는 알리지 않아 "안 닫힌다"로 보였다(실측).

## 대안
같은 대화를 여러 탭에서 이어서: 대화 기록이 엉킨다.
탭마다 git worktree: 동시 작업에는 이상적이지만 저장소에 작업 폴더를 만든다 — 필요해지면 따로 결정한다.

## 결과와 대가
같은 폴더에서 탭 여러 개가 동시에 파일을 고치면 턴별 변경이 섞인다(README 알려진 한계).
