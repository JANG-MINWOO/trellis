## 확인한 사실 (Claude Code 2.1.294)
- `--settings`로 넣은 훅은 대상 저장소의 훅과 **병합되어 둘 다 돈다** (실측).
- HTTP 훅: 헤더 `${VAR}` 보간은 `allowedEnvVars`에 있어야 함, 2xx 빈 응답은 no-op, 실패는 non-blocking. 페이로드에 `prompt_id`가 있어 턴 묶기에 씀.
- 새 폴더에서는 신뢰 확인 화면이 뜨고 기본 선택이 "No, exit". `--continue`에 이어갈 대화가 없으면 "No conversation found to continue"로 코드 1 종료.
- Claude는 파일을 Bash로도 만든다 → 변경은 훅이 아니라 git으로 계산(ADR-0014).
- Claude 안에서 Trellis를 띄우면 `CLAUDE_CODE_CHILD_SESSION` 등이 상속되어 새 세션의 대화 저장이 꺼진다 → 어댑터에서 지움(ADR-0015).
- xterm에서 Shift+Enter를 `ESC CR`로 보내면 Claude 입력창에서 줄바꿈이 된다 (실제 claude e2e로 확인).
- npm 11은 의존성 설치 스크립트를 막는다 → `package.json`의 `allowScripts`에 node-pty·esbuild 허용, node-pty `spawn-helper` 실행 권한은 `scripts/fix-node-pty.mjs`가 복구.
